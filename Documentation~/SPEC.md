# Bude Studio — SPEC

Personal, beginner-friendly AI game creation editor inside Unity for BudE404.
The AI engine is Bigfoot (the Bigfoot404 agent and its real tools). No other AI,
no fake functionality, no accounts, no subscriptions, no payments.

## The Workflow

Tell Bigfoot what you want → generate it → edit it visually → rig or animate it → playtest it.

## Capabilities (target)

1. **Build Anything** — describe the game in plain English; Bigfoot plans it
   (PLAN tab + chat), then creates objects, assets, and scripts.
2. **Visual Map Editor** — Bude Studio's factory creates standard Unity objects
   (sprites, platforms, primitives, lights). Editing happens with Unity's own
   scene tools: drag, drop, move, resize, rotate, layer, collision. Nothing is
   locked or proprietary.
3. **AI Art & Characters** — art generated by Bigfoot lands in
   Assets/BudeStudio/Art via the import pipeline with correct sprite settings,
   duplicate detection, and Asset Bible tracking.
4. **One-Click Rigging** — stage 5 (see ROADMAP). Frame-animation and bone
   rigging generation on top of imported character art.
5. **Make It Like This** — reference-image-driven changes arrive with the chat
   + import loop: send Bigfoot the reference, import the result, replace the
   sprite on the selected object.
6. **Bigfoot Automation** — Bigfoot operates Unity through the relay bridge
   (separate from this package) or through the chat hookup here. Missing
   dependency for in-window chat: the agent API key from MC.
7. **Beginner Interface** — big buttons, plain-English help text, tooltips,
   undo/redo (Unity-native, everything the factory makes is registered with
   Undo), backups (SETTINGS tab).
8. **Editable Everything** — all outputs are ordinary Unity assets and scenes.
   Generated assets are never baked or hidden.

## Architecture

- `Runtime/` — play-mode components (player controllers, collectibles, score,
  goal, camera follow). Referenced by generated starter scenes.
- `Editor/` — the Bude Studio window, Game Plan and Asset Bible data assets,
  chat transport, asset importer, object factory, 2D/3D map generators,
  project backups, settings, project state.
- `Tests/` — edit-mode sanity tests (config roundtrip, project state roundtrip,
  bible upsert, defensive reply extraction).

## Known dependencies / gaps (honest list)

- **Agent API key** (from MC) — required for in-window chat. Until it lands,
  chat falls back to opening the agent chat in a browser. The exact API JSON
  shape needs verification against the live endpoint; extraction is
  deliberately defensive.
- **Compilation verified?** No — written against Unity 6000.6 APIs; must be
  opened in the editor to confirm. Report console errors to Bigfoot.
- **Rigging/animation generation** — stage 5, not built.
- **Terrain sculpting** — stage 5, not built (map templates cover basics).
- **Lil Foots 2.5D template** — stage 6, not built (Lil Foots pipeline lives in
  its own repo and bridge; this toolkit gets the same art-import pipeline).
